# Number Guessing Game (1–50) — Python CLI

Command-line game where the player guesses a randomly generated number
between 1 and 50 within a limited number of attempts.

## How It Works
- Computer generates a random number between 1 and 50
- Player has a fixed number of attempts to guess it
- After each wrong guess, the game hints too high / too low

## Tech Stack
Python 3 (`random` · `input`)

## How to Play

```bash
python guessing_game.py
```

## Skills Demonstrated
Randomisation · Conditional logic · Loop control · User input handling
